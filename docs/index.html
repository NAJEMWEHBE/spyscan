What it does

Baseline, then diff

On a machine you trust, SpyScan snapshots processes, services, drivers, scheduled tasks, autostarts, network connections, and the mic/camera consent store. Every later scan is diffed against that baseline — new or changed persistence is what implants need and what SpyScan surfaces.

Known-spyware IOCs

Findings are checked against a short, cited list of mercenary-spyware indicators (implant process names, and C2 domains matched against this PC's DNS cache), with MITRE ATT&CK technique references on every finding so you can look up exactly what a signal means. Most published indicators target phones, so on Windows the baseline diff, signatures and behaviour carry the weight.

Canary tripwires

Decoy files that nothing legitimate should ever touch. If one is changed, moved or deleted, that alone raises an alert. Turn on Windows access auditing once with spyscan canary audit-setup (as admin), and a program that only reads or copies your fake passwords.txt raises an alert too, naming the program. No signature needed, so it can catch implants no IOC list knows yet.

Yours, locally

Everything runs and stays on your machine: no cloud, no account, no upload, no telemetry. The report is a local HTML/JSON file. The optional Windows Defender deep-scan invokes the AV already on your system.

If you think someone is watching you

Your safety matters more than any scan result. Software that watches you can also show the person behind it that you scanned, searched for help, or removed something, and removing it can make things more dangerous.

  • Document first, remove later. Keep the report (runs\last_scan.html and .json), take photos of what you find, and note the dates. Do not delete anything until you have a plan.
  • Plan from a device they have never had access to, such as a trusted friend's phone or a library computer.
  • Get help. The Coalition Against Stalkerware lists support organisations by country. For example: in the US, the National Domestic Violence Hotline (1-800-799-7233); in the UK, the National Domestic Abuse Helpline (0808 2000 247). In danger, call your local emergency number.
  • SpyScan leaves traces. It never removes anything, but its folder, its report and any decoy files can be seen by someone who uses this PC. spyscan canary clear removes the decoys.

Verify your download

The v0.2.0 exe is not code-signed yet. Check the hash before running it:

PS> Get-FileHash SpyScan.exe -Algorithm SHA256

a694bf98f6bf154fa925d97fd228f5efa9a61adea054ee9bcfd688a93519fac4  SpyScan.exe
8e325a58cab3e34466b3c2a2e13a996928bc6182382200042ef5c473c51c03f4  SpyScan-v0.2.0-win64.zip

Both files are built by the release workflow and carry a signed build attestation: gh attestation verify SpyScan.exe --repo NAJEMWEHBE/spyscan.

Cross-check it yourself: search the hash on VirusTotal. A few heuristic engines may flag any unsigned PyInstaller one-file exe — that packaging pattern (self-extracting Python runtime) resembles how some malware bundles itself, which is a known false-positive source. The source is open; when in doubt, build it yourself.

Prefer auditable? Clone the repo, pip install -e ., run spyscan-app (Python 3.13+).

Honest limits

A security tool that oversells its coverage is part of the problem. Read this before trusting a CLEAN verdict:

  • Autostart coverage is a subset of Windows' full auto-start surface. The built-in collector reads the core locations (Run keys, services, tasks, drivers); the fuller sweep — 63 populated locations vs the default build's 6 on the reference machine — requires installing Sysinternals autorunsc yourself, because its license forbids bundling it. The README documents exactly what goes unchecked (BootExecute, AppInit_DLLs, IFEO hijacks, credential providers, and more).
  • A scanner on a compromised machine can be lied to. A sufficiently privileged rootkit can hide from any userland scanner. SpyScan raises the bar; it is not a forensic guarantee.
  • Windows x64 only, desktop only. No phone or network-side coverage yet.
  • 0-click mercenary spyware is hard to catch for any endpoint tool. SpyScan focuses on the persistence and behavior most implants still need.
